## 🚀 Publicação no GitHub Pages / Publishing to GitHub Pages

1. Suba este repositório para o seu GitHub: `git remote add origin https://github.com/<usuario>/psvita-porting-wiki.git && git push -u origin main`.
2. No repositório, acesse **Settings** > **Pages**.
3. Em **Build and deployment** > **Source**, selecione **GitHub Actions**.
4. O workflow `.github/workflows/deploy.yml` compilará o site trilíngue automaticamente.

Previsão local com Python:
```bash
pip install mkdocs-material
mkdocs serve
```
